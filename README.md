1x Arduino Uno R3

1x 16x2 LCD Display

1x Pushbutton

1x Piezo Buzzer

1x 10 kΩ Potentiometer

1x 10 kΩ Resistor

1x 220 Ω Resistor

1x Mini Breadboard
